# پویش زمین

رابط کاربری فارسی و راست‌چین به‌همراه API روی Cloudflare Workers و ذخیره‌سازی D1.

## وضعیت آماده‌سازی

- رابط کاربری در `public/index.html` قرار دارد و Worker آن را از طریق Assets ارائه می‌کند.
- `src/index.js` مسیرهای ثبت‌نام، ورود، خروج، وضعیت نشست، سوابق اقلام و پست‌ها را فراهم می‌کند.
- `schema.sql` ساختار D1 شامل اطلاعات پروفایل کاربران، نشست‌ها، سوابق اقلام و پست‌ها را تعریف می‌کند.
- فایل `index.html` در ریشه مخزن نسخهٔ منبع بارگذاری‌شده است؛ نسخهٔ قابل ارائه از پوشهٔ `public` سرو می‌شود.

## مراحل لازم برای انتشار

1. در Cloudflare یک D1 Database با نام `pooyesh-zamin-db` بسازید و شناسه واقعی آن را جایگزین `REPLACE_WITH_CLOUDFLARE_D1_DATABASE_ID` در `wrangler.jsonc` کنید.
2. در محیطی دارای Node.js و Wrangler، اجرا کنید:
   ```sh
   npm install
   npx wrangler login
   npx wrangler d1 execute pooyesh-zamin-db --remote --file=./schema.sql
   npx wrangler deploy
   ```
3. آدرس `workers.dev` را از خروجی deploy بردارید و `/api/health` را بررسی کنید.

## محدودیت‌های شناخته‌شده

- استقرار واقعی انجام‌شده تلقی نمی‌شود تا زمانی که شناسه D1 معتبر و دسترسی حساب Cloudflare تأیید و دستور deploy با موفقیت اجرا شود.
- آپلود تصویر در پست‌ها به R2 نیاز دارد؛ API در حال حاضر تصویر فایل‌محور را صریحاً رد می‌کند. ارسال پست متنی قابل پشتیبانی است.
- سوابق «اقلام قابل تحویل» در D1 ذخیره می‌شوند؛ این به‌تنهایی به معنی انتقال تمام فاکتورها و سوابقی نیست که رابط کاربری در `localStorage` نگه می‌دارد.
- پیش از استفاده عمومی باید محدودسازی نرخ، تأیید شماره همراه، بازیابی گذرواژه، سیاست حریم خصوصی و آزمون امنیتی انجام شود.
