# پویش زمین

فرانت‌اند فارسی، راست‌چین و واکنش‌گرا برای ثبت پسماند خشک، مشارکت اجتماعی و نصب به‌صورت PWA روی Android و iOS.

## امکانات
- رابط روشن و تیره با انتخاب پایدار کاربر و پشتیبانی آفلاین PWA
- داشبورد وزن پسماند، ثبت پسماند، سوابق محلی و پیام‌های اجتماعی
- API حساب، پروفایل و پیام‌ها با نشست امن HttpOnly
- پشتیبانی نصب PWA روی Android و iOS

## میزبانی و API
- Cloudflare Pages پروژه را از پوشهٔ `public/` منتشر می‌کند.
- مسیر `functions/api/[[path]].js` درخواست‌های `/api/*` را به `src/index.js` می‌فرستد؛ D1 binding در تنظیمات Preview و Production پروژهٔ Pages قرار دارد.
- `wrangler.jsonc` تنظیمات استقرار مستقل Worker را نگه می‌دارد؛ تنظیمات Pages از داشبورد/پیکربندی Pages مدیریت می‌شود.
- GitHub Pages فقط نسخهٔ استاتیک را ارائه می‌کند؛ داده‌های مهمان در همان مرورگر می‌مانند و API هم‌مبدأ در آن میزبان وجود ندارد.

## D1 و پروفایل کاربران
- `schema.sql` ساختار پایهٔ D1 را برای ایجاد دیتابیس تازه تعریف می‌کند.
- API ثبت‌نام نام، نوع حساب، نشانی و محدوده را ذخیره می‌کند؛ ورود و پاسخ نشست نیز همین اطلاعات را برمی‌گردانند.
- قرارداد پیام‌ها شامل `authorName` و `createdAt` است.
- migration شمارهٔ 0004 ستون‌های پروفایل را به جدول موجود `users` اضافه می‌کند.
- بررسی خواندنی پایگاه متصل در 2026-10-31 نشان داد جدول‌های سوابق مکانی و ستون `capture_height_m` موجودند، اما ستون‌های پروفایل `users` وجود ندارند و جدول تاریخچهٔ migration نیز دیده نشد. روی این پایگاه migrationهای 0001 تا 0003 یا `schema.sql` را دوباره اجرا نکنید.
- پس از تهیهٔ نسخهٔ پشتیبان و بررسی مجدد `PRAGMA table_info(users)`، فقط migration 0004 را یک‌بار اجرا کنید:
  ```sh
  npx wrangler d1 execute pooyesh-zamin-db --remote --file=./migrations/0004_user_profile.sql
  ```
- این مخزن در این مرحله هیچ migration عملیاتی یا deploy اجرا نکرده است.

GitHub Actions بررسی syntax Worker، رابط‌های روشن/تیره، ذخیرهٔ انتخاب تم، رفتار آفلاین و dry-run تنظیمات Wrangler را اجرا می‌کند.
